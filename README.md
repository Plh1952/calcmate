# CalcMate — Free Online Calculators

80 free, fast, single-purpose calculators: finance, pregnancy, health, math,
statistics, geometry and unit conversions. Pure static HTML/JS — every
calculation runs in the visitor's browser, no backend, no tracking.

Deployed via GitHub Pages. All calculator definitions are generated from the
build scripts (kept outside this repo).

## Categories
Finance (27), School (5), Date & Time (4), Pregnancy (5), Health (7), Home (2), Math (10), Statistics (5), Geometry (9), Conversion (6) = 80 calculators.
