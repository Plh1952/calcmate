About the Aspect Ratio Calculator

Aspect ratio is width divided by height. Scaling keeps the ratio constant: new height = new width × (orig height / orig width). Common ratios: 16:9 (HD video), 4:3 (classic TV), 3:2 and 1:1. A 1920×1080 screen is 16:9.
